# Rishi Kiran — Actor · Model · Assistant Director

Portfolio website for Rishi Kiran, a Chennai-based actor.

A single static page: open `index.html` in a browser, or upload the whole folder to any static host (Hostinger, Netlify, GitHub Pages).

## Structure
- `index.html` — the whole site (HTML, CSS and JavaScript)
- `assets/img` — photos
- `assets/video` — compressed videos and their poster frames
- `assets/Rishi_Kiran_Resume.pdf`, `assets/Rishi_Kiran_Headshots.zip` — downloads

## Editing
- Swap a photo: replace the file in `assets/img` (same name) or change the `src` in `index.html`.
- Add a video: put the `.mp4` and a `.jpg` poster in `assets/video`, then add a `<video>` in the matching brand section of `index.html`.
- Showreel / Rudhra / untitled project links go in the `VIDEOS` list near the bottom of `index.html`.
